ОТЧЁТ О ПРОВЕРКАХ — 2026-10-31

ИТОГОВЫЙ СТАТУС:
PATCH_KIT_READY_NOT_ROUTER_VALIDATED

Готов набор для воспроизводимой локальной сборки. Готовый WinBox EXE
в этой среде не создавался. Подтверждения реального подключения нет.

ВЫПОЛНЕНО

1. Получены данные патчей из зафиксированного upstream commit:
   b22d97ee6fb222e14ff35151634bdac42a9f5d29.
   Данные: 20 участков, 12 логических групп. Переходы к добавленным
   блокам и размещение внутри хвоста секции проверены на уровне данных.

2. Написаны отдельные сборщики на Python и PowerShell; основной Windows-
   вариант не требует Python. Нет принудительного применения к чужой версии.
   В коде фиксированы SHA-256 входа и результата, а также отпечаток таблицы патчей.

3. Выполнены 59 автоматических тестов: PASS (включая импорт данных).
   - таблица участков, длины, границы и отсутствие пересечений;
   - точное применение замен к искусственному НЕИСПОЛНЯЕМОМУ PE-макету;
   - отсутствие изменений за пределами указанных участков и PE checksum;
   - независимый контрольный расчёт PE checksum, переносы, нечётная длина;
   - отказ при неверном размере, хеше, заголовке и исходных байтах;
   - отказ при повторном применении;
   - отказ публиковать результат с неверным хешем;
   - исходный файл не перезаписывается; существующий другой результат
     не заменяется; запись проверенного тестового результата атомарна;
   - текстовые проверки Windows-запускателей и констант PowerShell.

   Для отдельных тестов только внутри test-кода временно подменялись
   ожидаемые хеши на хеши искусственного макета. Это НЕ используется
   обычными сборщиками и НЕ является реальной сборкой WinBox.
   В производственном запуске режим отключения проверки хешей отсутствует.

4. Созданы инструкции, сведения об источниках, контрольные суммы файлов
   и ZIP. В комплект не включены тестовые EXE, pyc или сторонние бинарники.

НЕ ВЫПОЛНЕНО

- Скачивание реального оригинального EXE: недоступно из среды подготовки.
- Применение патчей к настоящему EXE и проверка его фактического хеша.
- Выполнение/полноценный разбор PowerShell Windows-движком: движка здесь нет.
  Текстовые проверки НЕ являются синтаксическим или runtime-тестом PowerShell.
- Запуск WinBox в Windows/Wine.
- Авторизация и работа с RouterOS по IP или MAC.
- Проверка CMR, Wi-Fi, контейнеров, прав доступа, Safe Mode, backup/export.
- Антивирусная проверка настоящего модифицированного EXE.
- Полный аудит безопасности upstream-патчей или исходного WinBox.

Проверка сборщика не доказывает, что приложение стабильно и безопасно
управляет конкретным устройством. Общий статус приложения — НЕ ПРОВЕРЕНО.
Автор upstream сообщает о собственном тесте hAP ax3 / RouterOS 7.25;
его результат не подменяет перечисленные невыполненные проверки.

КОМАНДЫ ЛОКАЛЬНЫХ ТЕСТОВ

python -m unittest discover -s tests -v
Полный вывод: tests\unit-tests.txt

ПУБЛИКУЕМАЯ ВЕРСИЯ: третьесторонние байты патча не включены в GitHub/ZIP.
Вместо этого при первой локальной сборке скачиваются данные из зафиксированного
исходника rodenasl и проверяются. Новый импортирующий PowerShell-код в Windows
на момент публикации отдельно не тестировался; прежние скриншоты относятся
к первому локальному набору без динамического импорта.
