# Security policy

This is an experimental, unofficial binary compatibility layer. It is **not** an official security-supported WinBox client.

## Supported version

Only the pinned source (WinBox 3.43 x64) and the patched SHA-256 listed in README.md are recognized. Future RouterOS versions, including any version after 7.25, are not guaranteed.

## Reporting vulnerabilities

Do not post passwords, session databases, router addresses or exploitable details in a public issue. Use GitHub's **Report a vulnerability** private disclosure feature, if it is enabled for this repository. If that feature is unavailable, first open a minimal issue asking maintainers for a private contact route, **without sharing sensitive details**.

The project does not collect credentials, intentionally disable Microsoft security products, or add Windows exceptions. Source integrity checks are not substitutes for antivirus, digital signatures or independent code review. Use a lab router/least-privilege account for first use and keep official WinBox 4 available.
