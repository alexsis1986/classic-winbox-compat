This package contains independently written PowerShell and Python builders,
Windows launchers, tests, and documentation. It is not a new implementation
of WinBox, an upstream release, or an official MikroTik product.
The patch design is credited to its upstream author, rodenasl.
No permission or support by MikroTik is claimed.

No third-party patch bytes are distributed by the public project. On first
local build, a fixed-revision upstream source file is downloaded as TEXT only,
verified against its Git blob SHA-1 and a SHA-256 patch-site fingerprint, and
parsed to source/patches.json (git-ignored; not redistributed).
The downloaded Python program is NEVER executed by our scripts.
The original WinBox executable is also downloaded only from MikroTik.

The original-file SHA-256 was cross-checked against the MikroTik downloads
page. The result SHA-256 is the upstream author's published expected value,
not a hash of a locally generated real WinBox file in this session.
