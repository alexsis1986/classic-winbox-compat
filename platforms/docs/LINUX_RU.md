# Установка на Linux — Classic WinBox 3.43 через Wine

**Исходники Preview 0.1.0-preview.1. Это не нативная Linux-пересборка.**

## 1. Требования

Нужны настольный Linux **x86-64 Intel/AMD**, Python 3.9+, Bash и доверенная установка Wine с поддержкой 64-битных Windows-программ. Linux ARM/Raspberry Pi не поддерживается. Одной консольной SSH-сессии без графической среды недостаточно. Wine в комплект не включён.

Пример установки зависимостей для Ubuntu 24.04 с подключёнными официальными репозиториями:

```bash
sudo apt update
sudo apt install python3 wine wine64
python3 --version
wine --version
```

Для других дистрибутивов используйте их актуальные инструкции Wine: имена пакетов и зависимости могут отличаться. Права администратора нужны только пакетному менеджеру ОС. **Не запускайте WinBox, Wine и наши запускатели/установщики через sudo.** Ссылки на пакеты Ubuntu приведены в SOURCES.md. Установка Wine сама по себе не подтверждает совместимость WinBox.

## 2. Исходники и ваш локальный EXE

Скачайте публичный выпуск исходников оболочек и полностью распакуйте его. Другой вариант — клонировать репозиторий и открыть `platforms`:

```bash
git clone https://github.com/alexsis1986/classic-winbox-compat.git
cd classic-winbox-compat/platforms
```

В отдельном ZIP исходников файл `build_packages.py` лежит в корне распакованной папки: откройте эту папку, второй переход `cd platforms` не нужен.

Нужен ваш локально подготовленный `WinBox3_Compat/winbox64.exe`, соответствующий Windows-комплекту v1.0.0, при наличии права использовать такую изменённую копию. Перенесите **только EXE** в личную папку; сохранённые сессии, резервные копии роутера и пароли не нужны. Оригинальный неизменённый WinBox 3.43 упаковщик оболочек не принимает. Проект не предоставляет разрешения на модификацию и распространение чужого кода. Перед использованием отдельного Windows-патчера прочитайте правовые оговорки.

Проверьте файл:

```bash
sha256sum "$HOME/Downloads/winbox64.exe"
```

Ожидаемый SHA-256 **исправленного** EXE:

```text
ac40890431762b588a7b7777d1ad48c54751dbfa2a3868450222dce757ec496d
```

Совпадение подтверждает только байты, а не безопасность, права или полную поддержку RouterOS.

## 3. Локальная сборка

В каталоге с `build_packages.py`:

```bash
python3 build_packages.py --audit-source
python3 build_packages.py --exe "$HOME/Downloads/winbox64.exe" --out ./private-build
```

Укажите фактический путь к своему EXE. Существующий результат не перезаписывается: для повторной сборки задайте другую папку `--out`. Создаются частные пакеты для Linux и macOS. **Их нельзя загружать в GitHub без разрешений: они содержат EXE.** Для публичного архива есть отдельный режим `--source-only`.

## 4. Проверка и запуск

```bash
cd private-build/ClassicWinBox343-Linux-x86_64-preview0.1.0
bash VERIFY_FILES.sh
bash WinBox.sh --doctor
bash WinBox.sh
```

`--doctor` проверяет хеш, платформу, версию Wine и графическое окружение. WinBox он не запускает и роутер не проверяет. При обычном первом запуске создаётся отдельный 64-битный профиль Wine. Адрес, логин и пароль вводите в самом WinBox: запускатель отклоняет такие аргументы командной строки.

Локально собранный Linux-архив можно распаковать на другом совместимом компьютере; продолжайте с этого раздела внутри распакованной папки.

## 5. Ярлык меню приложений

```bash
bash Install.sh
```

Установка выполняется только для пользователя: приложение — `~/.local/share/classic-winbox343/app-0.1.0-preview/`, ярлык — `~/.local/share/applications/classic-winbox343.desktop` (учитывается XDG_DATA_HOME). Существующие копии и ярлыки не перезаписываются. Wine и firewall установщик не настраивает.

Для нестандартного расположения Wine:

```bash
CWC_WINE_BIN=/absolute/path/to/wine bash WinBox.sh --doctor
```

Для запуска из меню запишите абсолютный путь к исполняемому файлу одной строкой **без кавычек и аргументов** в `~/.config/classic-winbox343/wine-path.txt` (учитывается XDG_CONFIG_HOME). Пароли туда не записывайте.

## 6. Диагностика, данные и удаление

По умолчанию профиль: `~/.local/share/classic-winbox343/wineprefix/`; журнал последнего запуска: `~/.local/share/classic-winbox343/logs/last-launch.log`. Отдельный профиль — **не защитная песочница**. Перед передачей журнала удалите личные данные; весь профиль публиковать нельзя.

Первую проверку проводите на тестовом роутере или с учётной записью только для чтения, по IP. Neighbors/MAC-подключения, новые поля, шрифты и масштабирование под Wine ещё не подтверждены. Ограничения v1.0.0 сохраняются. Не отключайте проверку хеша, антивирус или firewall ради запуска.

Фирменные иконки и шрифты не включены. Отсутствие иконки не говорит о наличии поддержки функции RouterOS. Допустимые локальные изображения должны оставаться вне публичных исходников.

Для удаления уберите только каталог `app-0.1.0-preview` и его `.desktop`-ярлык. Профиль и логи сохраните, если нужны настройки. Скрипты не удаляют сохранённые сессии автоматически.

**Проверки:** тесты используют имитацию Wine. Реальный Linux GUI и подключение к роутеру не подтверждены. Первоисточники зависимостей — [SOURCES.md](SOURCES.md).
