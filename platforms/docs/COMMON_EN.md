# Platform source preview — English guide index

Full platform-specific instructions are in LINUX_EN.md and MACOS_EN.md in this source directory.
Private packages now receive the corresponding complete guide as README_EN.md.

The public release contains no executable, Wine, artwork or patch bytes. A locally assembled
private package contains the user's own EXE and must not be redistributed without permissions.
Read the rights notes before using third-party software. This is not a native WinBox port;
real Wine GUI and router connectivity are not yet validated.
