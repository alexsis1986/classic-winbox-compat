# Classic WinBox 3.43 · запускатели Linux и macOS

**Исходники Preview 0.1.0-preview.1 · требуется Wine · это не нативная пересборка WinBox**

[English](README.md) | [Linux](docs/LINUX_RU.md) | [macOS](docs/MACOS_RU.md) | [Права и происхождение](docs/RIGHTS_RU.md)

Сохраняем классический Windows-интерфейс и запускаем вашу локально подготовленную WinBox 3.43 x64 через Wine. Здесь публикуются только собственные исходники запускателей, установщиков, упаковщика, тестов и документации. **WinBox, Wine, шрифтов, иконок MikroTik, сторонних исходников патча, машинных байтов патча и сохранённых подключений здесь нет.**

> **Экспериментальная версия.** Реальный запуск WinBox через Wine и подключение с Linux/macOS проектом ещё не подтверждены. Автотесты используют имитацию Wine и искусственные данные. Ранее подтверждённое пользователем Windows-подключение не подтверждает работу на Linux/macOS. Новые обработчики полей RouterOS эта оболочка не добавляет.

## Локальная сборка

Нужны Python **3.9+** и законно полученный, локально подготовленный совместимый EXE. В каталоге с `build_packages.py` выполните:

```bash
python3 build_packages.py --exe "/полный/путь/WinBox3_Compat/winbox64.exe" --out ./private-build
```

Принимается только исправленный EXE, соответствующий v1.0.0, с SHA-256:

```text
ac40890431762b588a7b7777d1ad48c54751dbfa2a3868450222dce757ec496d
```

Оригинальный неизменённый WinBox 3.43 — другой файл; упаковщик его отклонит. Упаковщик оболочек **не патчит, не скачивает и не запускает EXE** и не получает сторонние данные патчей. Уже существующий Windows-патчер основного репозитория — отдельный компонент с отдельными лицензионными вопросами. Использовать его следует только после определения разрешения или применимого законного основания; лицензия оболочек такого разрешения не предоставляет.

Созданные локально пакеты содержат ваш EXE и **не являются публичным выпуском исходников**. Не загружайте их в GitHub без необходимых разрешений.

## Публичный выпуск без бинарников

```bash
python3 build_packages.py --audit-source
python3 -m unittest discover -s tests -v
python3 build_packages.py --source-only --out ./source-build
```

Публикация использует явный список `SOURCE_FILES.txt`, отклоняет отсутствующие файлы, символические ссылки, нетекстовое содержимое и неожиданные файлы в исходниках, кроме явно исключённых локальных каталогов сборки и кэша. SHA-256 создаются заново. Одного `.gitignore` для такой проверки недостаточно.

Отдельный workflow создаёт **предварительный** выпуск `platforms-source-v0.1.0-preview.1`. Он не изменяет и не переименовывает Windows-релиз `v1.0.0`, не загружает локальные сборки с EXE и не перезаписывает уже существующие выпуски.
