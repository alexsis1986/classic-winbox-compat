# Linux/macOS launchers — source-only preview 0.1.0-preview.1

## English

Original platform launcher, installer, packaging and test source for running a locally
prepared classic WinBox 3.43 x64 through Wine. Full Linux/macOS installation guides are
included in English and Russian. This is **not** a native client and does not implement
new RouterOS fields. It does not replace the Windows release v1.0.0.

**Public contents:** sources, scoped MIT license, rights/provenance notes and tests.
**Excluded:** EXE/DLL, Wine, logos/icons/fonts, third-party patch bytes/source, router
packages, sessions, passwords and private local builds. The public archive is made from
an explicit text-file allowlist and includes SHA-256 checksums.

Supply your own compatible local EXE only where your rights allow. Private assembled
packages are not authorized public redistributions. No guarantee of non-infringement is
made; see the rights notes. Mock-only CI does not validate real Wine GUI or RouterOS
connections. This release is deliberately marked **Pre-release**.

Start with README.md, docs/LINUX_EN.md or docs/MACOS_EN.md inside the source archive.

## Русский

Исходники запускателей, установщиков, упаковщика и тестов для локально подготовленного
классического WinBox 3.43 x64 через Wine. Полные инструкции Linux/macOS на русском и
английском. Это **не** нативный клиент; новых полей RouterOS оболочка не добавляет.
Windows-релиз v1.0.0 не заменяется.

В публичном архиве только исходники, ограниченная своим объёмом MIT-лицензия, сведения
о правах и тесты. EXE/DLL, Wine, фирменных изображений/шрифтов, чужих байтов/исходников
патча, пакетов роутера, сессий, паролей и частных сборок нет. Используется явный список
текстовых файлов; SHA-256 включены.

Ваш совместимый EXE используется только локально и при наличии прав. Локальная сборка
не предоставляет разрешения распространять чужое ПО. Отсутствие нарушений юридически
не гарантируется. Тесты с имитацией Wine не подтверждают реальный GUI и подключение
к RouterOS. Выпуск намеренно помечен **Pre-release**.

Начните с README.ru.md, docs/LINUX_RU.md или docs/MACOS_RU.md внутри исходного архива.
